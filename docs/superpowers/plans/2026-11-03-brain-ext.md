# brain-ext Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Notion metin aynası, güvenli taslak gönderimi, yerel hibrit arama ve OpenCode yönergeleri; yalnız sentetik doğrulama.

**Architecture:** Ayrı Python paketi; config/mdio ortak güven sınırları, httpx istemcisi ve state tabanlı pull/push, bağımsız SQLite arama indeksi. CLI yalnız bu servisleri birleştirir. Gerçek bağlantılar/kurulum Faz B kapısındadır.

**Tech Stack:** Python 3.11+, argparse/tomllib/sqlite3, httpx, PyYAML, optional fastembed/numpy/sqlite-vec; pytest ve ruff.

**Spec:** `docs/spec/NOTION-BRAIN-AGENT-BRIEF.md`, `docs/spec/BRIEF-EK-1-KESIF-SONRASI.md` (ek öncelikli).

## Global Constraints

- Yalnız proje `.venv` bağımlılıkları; gerçek model indirme yok.
- Kullanıcı vault'u/Notion/OAuth/OpenCode ayarlarına erişim yok.
- Kod/commit İngilizce; kullanıcı mesajları/doküman Türkçe. Her yazan komutta dry-run.
- JSON mirror, untrusted, arşiv status, allowlist/private filtreleri, taslaklar varsayılan arama dışında.
- Her faz: RED → GREEN test, tam suite, ruff, commit. Faz 4 sonunda dur.

## Review Focus

- Symlink/junction ve yol kaçışı: mdio/config/index güven sınırlarında reddet.
- Durum bozulması veya eksik keşif: üzerine yazma/arşivlemeyi fail-closed tut.
- POST başarılı ama yanıt belirsiz: pending marker ile uzlaştır; yeniden POST yok.
- Gizlilik değişen not: eski indeks kaydını temizle; neighbors/snippet ile sızdırma yok.
- Model/boyut/token bütçesi: sessiz kırpma veya karışık vektör yok; model olmadan metin modu.
